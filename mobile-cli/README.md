# Mobile CLI Companion Bridge

This directory contains the companion mobile bridge workstream for iPhone and
Android variants of the BVR-CLI experience.

```
mobile-cli/
  ios/           BvrCompanion.xcodeproj — see ios/README.md
  android/      reserved; native Kotlin vs. a shared Flutter codebase is open
  web-preview/  HTML/CSS prototype for zero-compile UI iteration
```

Use the docs plan for the authoritative outline:
[`../docs/MOBILE.md`](../docs/MOBILE.md). The host side is the NODE agent
documented in [`../docs/NODES.md`](../docs/NODES.md), not a separate server.
