# BVR-CLI Companion - Android

This directory is reserved for the Android Jetpack Compose or Flutter scaffold. We are currently evaluating whether to unify both iOS and Android under a single Flutter codebase for parity with the desktop NODE features, or proceed with native Kotlin.

## NODE Testing

To test the NODE features on Android during beta, we will connect to the FastMCP SSE port (e.g. `http://<laptop-ip>:8811/mcp/sse`) or the BVR WebSocket endpoint.
