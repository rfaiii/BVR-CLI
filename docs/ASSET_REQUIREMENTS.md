# BVR-CLI Asset Requirements

To create the "sharpest looking README ever" and ensure a perfect onboarding experience, we need to generate the following high-quality image and video assets.

## 1. Hero & Onboarding Assets
- **[ ] `demo-auth.gif` or `.mp4`:** A crisp, high-framerate animation showing the user typing `bvr auth <LICENSE_KEY>` and instantly getting a verified checkmark and the neon green beaver mascot.
- **[ ] `demo-usage.gif` or `.mp4`:** A fast-paced, high-quality showcase of opening BVR, finding a file in the File Finder, and firing off a quick prompt to Ollama.
- **[ ] `demo-install-mac.gif`:** A quick 3-second loop showing dragging `BVR.app` into the `Applications` folder on a macOS UI.

## 2. Feature Spotlight Screenshots
*All screenshots should have consistent padding, use a beautiful terminal background (like Ghostty or a clean shadow effect), and highlight specific features.*
- **[ ] `menu-models.jpg`:** High-res capture of the local Ollama models dropdown (`Ctrl+L`), showing the green diamond status indicators.
- **[ ] `home-menu.jpg`:** The absolute best, most appealing shot of the BVR landing screen with the ASCII art and resource bars fully populated.
- **[ ] `file-finder.jpg`:** A screenshot of the File Finder (`Ctrl+Shift+F`) showing rich metadata, previews, and clean typography.
- **[ ] `notification-select.jpg`:** A showcase of the toast/notification system in the bottom right corner.

## 3. Theming & Customization
- **[ ] `theme-pink.jpg`:** Showcase the interface using the Pink theme palette.
- **[ ] `theme-purple.jpg`:** Showcase the interface using the Purple theme palette.
- **[ ] `theme-green.jpg`:** Showcase the default neon green "Hacker" aesthetic.

## Notes for Generation
- Use a tool like **Cleanshot X** or a code snippet beautifier frame.
- Ensure the terminal font is perfectly readable (e.g., JetBrains Mono, Fira Code, or standard Ghostty/Apple Silicon defaults).
- You can record these locally using your actual setup for the final production versions.
